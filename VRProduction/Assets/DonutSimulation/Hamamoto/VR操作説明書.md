# ドーナツシミュレーション VR操作説明書

## VRコントローラー操作

### Aボタン
| 操作 | 説明 |
|------|------|
| 冷蔵庫を開く | 冷蔵庫に向かってAボタン |
| 食材を取る | 食材に向かってAボタン |
| 揚げたドーナツを取る | フライヤーに向かってAボタン |

### Bボタン
| 操作 | 説明 |
|------|------|
| 時間を動かす | ゲーム内時間の操作 |

### 右グリップ（GripButtonR）
| 操作 | 説明 |
|------|------|
| チョコを付ける | ホットポットに向かってグリップ |
| フライヤー起動/停止 | フライヤーに向かってグリップ |

### アイテム操作
| 操作 | 説明 |
|------|------|
| 食材を入れる | アイテムを掴んで鍋やフライヤーの上で離す |

---

## ドーナツの作り方

1. 冷蔵庫からドーナツ生地を取る（Aボタン）
2. フライヤーの上で生地を離してドロップ
3. 右グリップでフライヤー起動
4. タイマー完了後、右グリップでフライヤー停止
5. Aボタンで揚げたドーナツを取る
6. ホットポットに向かって右グリップでチョコを付ける
